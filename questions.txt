2️⃣ What can we still improve?

-Feature Engineering
Create more meaningful features, e.g., group rare titles, encode cabin deck, combine family size with passenger class.
Handle categorical variables more systematically (avoid unseen categories in test).

-Modeling
Tune hyperparameters for RF and XGBoost using GridSearchCV or RandomizedSearchCV.
Try other algorithms (SVM, LightGBM, etc.) to see if accuracy improves.

-Pipeline Robustness
Ensure train/test feature columns always match. Currently, unseen/missing columns in test can break predictions.
Use ColumnTransformer or sklearn.pipeline.Pipeline to keep preprocessing consistent.

-Evaluation Metrics
Accuracy alone may not capture performance. Consider precision, recall, F1-score, ROC-AUC.

-Scaling & Normalization
Logistic Regression may converge faster and perform better if features are scaled.

-Reproducibility
Set random seeds consistently across all models.
Save preprocessing steps (like encoders) so the test set can be processed exactly like the training set.
